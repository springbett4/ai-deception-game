Drop optional student portraits here for index4.html. Each file is used
automatically if present, otherwise the generated gradient avatar is shown.

Filename should be the student's name, lowercased, spaces replaced with
hyphens, as a .png (the hyphen-less form also works, e.g. airikurosawa.png):

- airi-kurosawa.png
- kaito-mizuno.png
- yui-tachibana.png
- sora-ichinose.png
- nadeshiko-amamiya.png
- haruto-serizawa.png
